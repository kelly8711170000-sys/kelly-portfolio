01 Project Background

從人工發放走向線上化

hub 以整合辦公多元服務為核心，讓企業透過線上平台管理契約與使用各項辦公服務。

其中，優惠券是企業契約中約定的服務權益，由承辦依契約內容定期發放。由於優惠券為新服務，初期以人工方式發放，且尚未建立明確的作業 SOP，實際執行過程中逐步調整。

因此本次專案希望將優惠券發放流程搬到平台上，建立完整的線上流程，降低人工處理成本。

02 Goals

流程改善與創造服務價值

我們期望透過優惠券流程線上化：

提升管理效率

減少優惠券印製、倉儲及人工管理成本。

提升租戶體驗與黏著

提供符合租戶需求的服務，強化租戶對平台的黏著。

擴大平台服務價值

掌握使用狀況與租戶偏好，作為服務優化及商家合作的依據。

03 Challenge

釐清流程規則與數據需求

01

缺乏標準化作業流程

原本以人工方式發放，缺乏明確 SOP，需要重新梳理現有作業流程與規則。

02

釐清跨角色分配方式與異動規則

優惠券涉及樓管、企業管理者與員工，需釐清各角色的操作流程，以及發券張數、契約人數異動時的分配規則。

03

定義數據分析範圍

釐清現階段數據分析目的與所需資訊。

05 Solution

建立完整的優惠券流程

針對「準備與發放 → 分配 → 兌換 → 使用成效」四階段，我們整合出對應的解法與價值：

Building Manager Corporate Admin Employee Account Manager

準備與發放

解法

設定優惠券內容、發放對象與週期，依規則發放給企業、員工。

價值

減少人工整理與發放作業，降低管理成本。

分配

解法

依照分配規則，設定員工可領取張數。

價值

簡化員工優惠券分配作業，降低人工處理負擔。

兌換

解法

依優惠券狀態分類，且可透過店家、優惠券名稱搜尋優惠券。

價值

方便員工查找可使用的優惠券，提升兌換便利性。

使用成效

解法

呈現發放大樓各優惠券每次發放的使用率。

價值

追蹤優惠券使用情形，了解實際成效與表現差異。

07 Next Step

未來優化

08 Reflection

從流程執行到產品思考

回顧整個專案，有三個地方讓我對「把流程搬上平台」這件事有了更完整的理解：

1

先釐清規則，再系統化

原以為只是把人工流程搬上平台，實際梳理後才發現，先釐清原有作業規則，才能決定哪些流程適合系統化。

2

從角色情境思考產品

不同角色關注的事情不同，從樓管、承辦、管理者到員工的完整流程思考，才能找到真正需要解決的問題。

3

上線後才是驗證的開始

先建立完整流程，再透過實際使用數據與回饋，持續調整後續功能。
