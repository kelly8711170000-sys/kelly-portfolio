01 Project Background

從人工發放走向線上化

hub 以整合辦公多元服務為核心，讓企業透過線上平台管理契約與使用各項辦公服務。

其中，優惠券是企業契約中約定的服務權益，由承辦依契約內容定期發放。由於優惠券為新服務，初期以人工方式發放，且尚未建立明確的作業 SOP，實際執行過程中逐步調整。

因此本次專案希望將優惠券發放流程搬到平台上，建立完整的線上流程，降低人工處理成本。

02 Goals

從流程改善創造服務價值

我們期望透過優惠券流程線上化：

降低營運成本

減少優惠券印製、倉儲及人工管理成本。

累積使用數據，協助營運決策

掌握優惠券使用狀況與租戶偏好，作為後續服務優化依據。

串聯商家與企業租戶價值

提供符合租戶需求的優惠，同時增加商家曝光與潛在客流，吸引更多商家與企業租戶加入，持續擴大平台服務價值。

03 Challenges

釐清角色與使用流程

團隊在啟動設計前，先透過訪談釐清了兩件事：

01

確認線上流程、角色

透過訪談了解現行優惠券作業方式，釐清從建立、發放、分配到使用的完整流程，以及各階段參與的角色。

02

釐清角色使用情境

從各角色的使用情境，進一步了解其操作需求：

樓管｜上架 / 發放優惠券
  • 設定優惠券內容、發放數量與期間
  • 掌握發放狀況與剩餘狀況
企業管理者｜管理 / 分配優惠券
  • 查看企業可使用的優惠券
  • 依需求選擇員工並分配優惠券
員工｜兌換優惠券
  • 各狀態優惠券的使用資訊
  • 於商家端出示優惠券完成兌換

05 Key Findings

找出流程中的關鍵需求

除了基本流程與角色需求外，透過訪談進一步發現幾項後續設計需特別考量的情境：

1

優惠券數量異動

因應企業擴編，樓管增加發放數量後，管理者同步調整分配員工、張數。

2

分層管理不同契約

讓樓管、企業管理者掌握優惠券的契約歸屬、張數與分配狀況。

3

快速找到優惠券

依店家、到期時間等條件篩選，快速找到並完成兌換。

06 Solutions

建立完整的優惠券流程

針對「上架 → 分配 → 兌換 → 追蹤」四階段，我們整合出對應的解法與價值：

上架優惠券

解法

標準化設定流程，於指定時間由系統自動發放。

價值

降低人工作業成本。

管理 / 分配優惠券

解法

依契約區分適用的優惠券，讓樓管、管理者可以依需求查看優惠券。

價值

清楚掌握不同契約的權益與分配狀況。

兌換優惠券

解法

依狀態、到期時間管理優惠券，並以店家、優惠券名稱快速搜尋。

價值

縮短找券時間，提升兌換便利性。

追蹤使用狀況

解法

以時間、發放狀態與使用狀況管理兌換紀錄。

價值

快速掌握發放與使用情形，累積數據資料作為後續服務優化依據。
